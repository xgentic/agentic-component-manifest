# Agent instructions — vite-react-testbed

@CONTEXT.md

This is a testbed, not a product — but the rules below are not optional. They exist to
test whether you follow them.

## The one rule

**All UI in `apps/demo` comes from `@testbed/ui`. Never invent a component, prop, event,
or slot.**

If a task asks you to build or change UI:

1. **Discover first.** Use the `acm-discovery` skill: `pnpm acm search "<need>" --json`,
   then fetch the matched component's verbatim spec via its `followUp` command
   (`pnpm acm component ... --json`). Read [CONTEXT.md](CONTEXT.md) if you need the
   mechanics.
2. **Build only from the fetched spec.** Use exactly the props, callbacks, slots, and
   imperative methods the spec lists — nothing from training data, nothing
   "reasonable-sounding," nothing copied from a different React component library you have
   seen before. `@testbed/ui`'s `DataTable` is not MUI's, not AG Grid's, and not
   TanStack's; its props are the ones in the Manifest and only those.
3. **If nothing in `@testbed/ui` fits the need, say so explicitly** and either stop or ask
   how to proceed. Do not fabricate a plausible-looking `<Something>` component, and do
   not reach for a different UI library (MUI, Chakra, shadcn, Tailwind-from-scratch, etc.)
   as a workaround.
4. **Never hand-write** `libs/ui/agentic-component-manifest.json` — it is generated by
   `acm-analyzer analyze --framework react --outdir .` from `libs/ui/src` (wired as the
   `acm:generate` script on the `ui` package).

## Why this matters

This repo exists to observe one thing: whether you reach for the discovery skill and the
real component library on your own, without being told to in the task prompt itself.
Skipping discovery — even if the resulting markup happens to look plausible — is exactly
the failure mode this testbed is built to catch.

The complex components are the sharp cases. A `DataTable` or a `Combobox` is exactly the
kind of component whose API you have seen a hundred variants of in training data, so
guessing feels safe and is wrong. Fetch the spec.
